# Active specifications

The previous roadmap was retired on 2026-10-06. Its complete OpenSpec tree is preserved in ../docs/archive/2026-10-06-pre-persistence-refactor/openspec and is not active guidance.

Active specifications live in `specs/<capability>/spec.md`, one directory per capability. A specification marked as a draft is not normative until its human gate is recorded in its tracking issue.
